# Free AI Video Generators — Verified November 2026

A curated directory of every high-quality AI video generator with a **genuinely working free tier** — all in one place, strictly curated, no junk.

Open `index.html` in any browser. No build step, no server, no paid APIs, no sign-up. Search and filter by clip length, watermark, and free-tier type.

## How this list was verified

Every free limit above was checked in November 2026 against the tool's own pricing or help page, or against at least two independent November 2026 comparisons that cite those pages. Two pages were read directly on 10 November 2026:

- **pika.art/pricing** — Free plan: "Monthly credits: 0 · credit packs only", "No watermark: Yes", "Commercial license: No".
- **lumalabs.ai/pricing** — no free ($0) plan listed; "Additional Details" mentions "free trial credits" only.

Free tiers change often — sometimes monthly — so always re-check the official pricing page before planning production around a limit. Sources consulted include the vendors' own pricing/help pages and the November 2026 roundups on overchat.ai, mitpo.io, krea.ai, theairankings.com, ecomobi.com and ampm-aiops.com.

## How to use this directory

1. Open `index.html` in a browser.
2. Use the search box to find a tool by name, model, or feature ("sound", "no watermark").
3. Use the filters: type (daily free / one-time trial / self-hosted), minimum clip length, and watermark.
4. Click a tool's name to open its official site. Check its pricing page before you commit to a workflow.

## How to contribute

This is a community directory — corrections and new tools are welcome.

1. Fork this repository.
2. Make your change (add a tool, fix a limit, update a link).
3. Include your source: a link to the tool's official pricing or help page, and the date you checked it.
4. Open a pull request with a short description of what changed and why.

Rules for additions: only tools with a **verified, working free tier** (or genuinely free open-source software). No resellers, no scams, no dead tools, no tools whose free tier is 0 credits. If a free tier disappears, open a PR to move the tool to "Not included — and why".
